# 簡介
以 **ASP.NET Core MVC** 為後端架構製作的簡易購物網站，並使用**SQLite**資料庫來儲存資料。
# 使用流程
- **購買流程**:找到喜歡的商品，點選立刻購買/加入購物車按鈕，兩者的差別:
  - 立刻購買:將商品加入購物車後，會跳轉到購物車頁面。
  - 加入購物車:只將商品加入購物車不跳轉，可以繼續選購商品。<br>
  - :warning:注意:當購物車已存在商品，兩者都會跳出警示。<br>
- **新增商品**:進入新增商品頁面，填好資料送出。
- **修改商品**:進入修改商品頁面，找到要修改的商品，點選修改商品按鈕，修改資料完成後送出。
- **刪除商品**:進入刪除商品頁面，找到要刪除的商品，點選刪除商品按鈕，會讓你再確認一次，確認無誤點選確認。
- **使用者註冊**:進入登入頁面，填好要註冊的帳號密碼，點選註冊按鈕。
# 資料欄位限制
- **商品名稱**:不能空白、不能重複。
- **商品描述**:可以空白。
- **商品價格**:不能為負(Ex:-10)、不能0開頭(Ex:012)。
- **商品圖片**:可以不上傳檔案。格式限制:**jpeg**、**png**。
- **帳號**:不能空白、不能重複(註冊時)、不能輸入中文或全形符號。
- **密碼**:不能空白。
# 使用者權限
**未登入**:只能購買商品。<br>
**已登入**:依權限可分為:<br>
:small_orange_diamond:**user**:可以新增、修改、購買商品，有購物紀錄，但**不能刪除商品**。<br>
:small_orange_diamond:**root**:全部都可以，**包含刪除商品**。<br>
:bangbang:特別注意:使用者只能修改自己新增的商品。Ex:商品是user1新增的，只有user1能修改，其餘使用者不行，即使他的權限為root。

# RWD
所有頁面皆採用RWD設計確保版面保持美觀，**寬度**最小可到**300px**，**高度**最小可到**300px**。當**寬度<500px**或**高度<601px**登入頁面的動畫會取消。建議使用Chrome瀏覽器。
# AJAX
為了讓使用者體驗更加流暢，分別在立刻購買、加入購物車、購物車修改商品數量、購物車移除商品、購物車數量，使用了AJAX。
# 背景服務
我建立了一個背景服務會定期清理購物車，它只會清理未登入者的商品，目前是設定10分鐘清理一次，支援即時修改時間，這樣可以在不關閉網站的情況下修改，賦予更大的靈活性。<br>
建立動幾:當網站長時間運行，勢必會累積數量可觀的資料，加上我儲存商品的方式，對於未登入者來說，只要關閉瀏覽器等同無效，但這些資料仍然佔據儲存空間，所以勢必得清理釋放儲存空間。這項技術日後也能使用在其它需要定期執行的背景任務。
<a name="SSE"></a>
# SSE(Server-Sent Events)
為避免未登入的使用者感到困惑，當購物車被清理時，會向前端發送通知，讓頁面彈出警示訊息告知使用者。
# 安全性
:sparkle:**CSRF防護**:所有表單的傳送皆採用此防護，為了更進一步強化安全性，除了首頁、商品關鍵字查詢，其它路由皆使用POST請求，同樣受到CSRF防護。<br>
:sparkle:**SQL注入攻擊防護**:所有資料庫操作，皆使用參數化查詢來操作。<br>
:sparkle:**密碼加密儲存**:使用者的密碼是經過加密再儲存，而不是直接存進資料庫，縱使資料庫真的外洩，也無法得知真正的密碼。<br>
:sparkle:**檔案指紋辨識**:偵測檔案指紋確認檔案真實格式，避免惡意人士透過修改副檔名，上傳惡意檔案。<br>
:sparkle:**重新編碼儲存檔案**:透過讀取檔案再儲存，等同重新編碼一次，可以去除隱藏在檔案中的惡意編碼。<br>
# 開始體驗
1. **環境建置**:請先至[https://dotnet.microsoft.com/zh-tw/download/dotnet/9.0](https://dotnet.microsoft.com/zh-tw/download/dotnet/9.0)下載ASP.NET Core 執行階段 9.0.16 並安裝。
2. **部屬程式碼**:下載此頁面的[publish.zip](./publish.zip)，並解壓縮。
3. **啟動網站**:解壓縮完，進入publish資料夾，執行啟動網站.exe。
4. **連線到網站**:開啟瀏覽器，連線到[http://localhost:5000](http://localhost:5000)，開始使用。
